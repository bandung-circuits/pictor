# 图尔敏论证图 / Toulmin Diagram

## 适用场景

按**图尔敏论证模型**拆解一个论证的完整结构，展示主张（Claim）、数据（Data）、保证（Warrant）、支持（Backing）、限定（Qualifier）和反驳（Rebuttal）之间的逻辑关系。

## 信息结构特征

当源文本包含以下特征时，适合使用图尔敏论证图：

- 明确的论点/主张及其支撑证据
- "因为 A，所以 B"（数据→主张）
- 隐含的推理规则（"之所以 A 能推出 B，是因为..."）
- 对论点的限定条件（"除非..."、"在...条件下"）
- 反驳或例外情况

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| Claim（主张） | 论证的核心结论 | 右侧突出显示的矩形 |
| Data（数据） | 支持主张的事实/证据 | 左侧矩形 |
| Warrant（保证） | 连接数据与主张的推理规则 | 数据→主张连线下方 |
| Backing（支持） | 支撑保证的进一步依据 | 保证下方 |
| Qualifier（限定） | 限定主张成立的程度 | 主张上方或旁边的修饰 |
| Rebuttal（反驳） | 主张不成立的条件 | 主张下方，用不同颜色标识 |
| 连线 | 逻辑推导关系 | 带箭头的线 |

## 布局原则

- **从左到右**：Data → Warrant → Claim 的逻辑流向
- **保证在下方**：Warrant 和 Backing 位于主推理线的下方
- **反驳突出**：Rebuttal 用不同颜色（如红色）标识
- **标签清晰**：每个元素的角色标签（D/W/C/B/Q/R）明确标注
- **单一论证**：一张图只展示一个完整论证，复杂论证拆分为多张
