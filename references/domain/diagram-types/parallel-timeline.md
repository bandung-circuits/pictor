# 平行时间线 / Parallel Timeline

## 适用场景

**多条并行的时间线对照展示**不同领域、地区或主题的同步演变。适合展示跨领域的历史对比、多国并行发展、多线程叙事。

## 信息结构特征

当源文本包含以下特征时，适合使用平行时间线：

- 同一时期内多个领域/国家/主题的并行发展
- "与此同时，在另一个领域..."
- 不同线索之间存在时间上的呼应或因果关系
- 需要对比不同维度的演变节奏
- 多线程的历史叙事

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| 多条时间轴 | 各自代表一个领域/线索 | 平行的水平线 |
| 时间刻度 | 统一的时间参照 | 顶部或底部的共享刻度 |
| 事件标记 | 各线索上的具体事件 | 各轴上的节点和标签 |
| 跨线关联 | 不同线索间的因果/影响 | 连接两条轴的虚线或箭头 |
| 线索标签 | 标识每条时间线 | 左侧或右侧的分类标签 |

## 布局原则

- **垂直排列**：多条时间线从上到下平行排列
- **时间对齐**：所有线索共享同一时间刻度
- **颜色区分**：每条线索用不同颜色
- **关联清晰**：跨线索的关联用连线明确标出
- **间距充足**：各线索之间留够空间放置跨线关联标记
