# 证据雷达图 / Evidence Radar

## 适用场景

在**多个维度轴上展示评估结果**，形成雷达/蛛网形状，直观比较各维度的强弱。适合多维度评估、证据质量对比、能力评估、方案综合评分。

## 信息结构特征

当源文本包含以下特征时，适合使用证据雷达图：

- 对同一对象在多个维度上的评估
- "在 X 方面表现优秀，但在 Y 方面不足"
- 多个指标的综合评分
- 多个方案/候选人的对比评估
- 证据链在不同方面的强度差异

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| 维度轴 | 各评估维度 | 从中心向外辐射的轴线 |
| 数据多边形 | 各维度得分连线 | 连接各轴上得分点的封闭区域 |
| 刻度环 | 得分参照 | 同心圆或同心多边形 |
| 维度标签 | 标识每个维度 | 轴线末端的文字 |
| 多对象叠加 | 对比多个对象 | 不同颜色/线型的叠加多边形 |

## 布局原则

- **维度数适中**：5-10 个维度最佳
- **均匀分布**：各维度轴等角度分布
- **刻度统一**：所有维度使用相同的评分范围
- **颜色区分**：叠加多个对象时用不同颜色和透明度
- **标签可读**：维度标签不相互重叠
