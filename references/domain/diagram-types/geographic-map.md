# 地理分布图 / Geographic Map

## 适用场景

在**地理空间**上展示数据、事件或现象的分布，呈现空间模式、区域差异、扩散路径等。

## 信息结构特征

当源文本包含以下特征时，适合使用地理分布图：

- 涉及多个国家、地区或地理位置的数据
- "在 X 地区...而在 Y 地区..."
- 现象的地理扩散或传播路径
- 区域间的对比或差异
- 地缘政治分析

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| 地图底图 | 地理参照 | 简化的区域/国家轮廓 |
| 热度着色 | 数值的地理分布 | 色阶填充（浅=低，深=高） |
| 标记点 | 具体位置的事件/数据 | 圆点，大小反映数值 |
| 路径/箭头 | 流向或扩散方向 | 连接两地的曲线箭头 |
| 图例 | 颜色/大小的含义 | 边栏的说明 |

## 布局原则

- **地理准确**：位置应大致对应真实地理方位
- **简化底图**：去除不必要的地理细节，突出数据
- **色阶直觉**：用直觉性的色阶（如红=高、蓝=低）
- **标签不遮挡**：文字标签不遮挡关键区域
- **比例尺**：如果距离有意义，提供比例尺参考
