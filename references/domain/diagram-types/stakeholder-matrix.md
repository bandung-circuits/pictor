# 利益相关方矩阵 / Stakeholder Matrix

## 适用场景

在**二维坐标轴上定位各利益相关方**，展示其影响力、利益、立场等维度的相对位置。适合分析多方博弈、权力格局、政策利益关系。

## 信息结构特征

当源文本包含以下特征时，适合使用利益相关方矩阵：

- 涉及多个参与方/利益相关方
- 描述了各方的影响力大小或利益程度
- "A 是关键决策者"、"B 的利益受到直接影响"
- 权力-利益、影响-意愿等二维分析
- 需要区分"应该重点关注谁"

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| 二维坐标轴 | 定义分析维度 | X 轴（如利益程度）、Y 轴（如影响力） |
| 象限标签 | 标识四个区域的策略含义 | 如"重点管理"、"保持满意"等 |
| 利益相关方标记 | 定位各参与方 | 圆形标记，大小可反映第三个维度 |
| 标签 | 标识每个参与方 | 标记旁边的文字 |

## 布局原则

- **坐标轴语义明确**：两个维度的含义必须清晰标注
- **象限含义**：四个象限各有明确的管理策略含义
- **避免重叠**：当标记密集时适当偏移，保持可读性
- **颜色区分**：可用颜色区分不同类型的利益相关方（如政府、企业、社会组织）
