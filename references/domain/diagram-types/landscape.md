# 全景图 / Landscape Map

## 适用场景

**鸟瞰式展示某个领域的整体格局**，包括主要参与者、思想流派、技术生态或市场格局的全貌。适合在一张图中呈现一个领域"谁在做什么、各占什么位置"。

## 信息结构特征

当源文本包含以下特征时，适合使用全景图：

- 一个领域内多个参与者/流派/技术的概览
- "该领域主要分为...几大方向"
- 竞争格局、生态系统的描述
- 学术领域中不同研究方向的分布
- 需要一张图让读者对整个领域有全局认识

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| 区域/地带 | 不同方向或子领域 | 色块区域或地图式分区 |
| 实体标记 | 具体参与者/技术/流派 | 区域内的图标或标签 |
| 边界 | 子领域间的界限 | 渐变色过渡或虚线 |
| 关系连线 | 跨领域的关联 | 虚线或淡色连线 |
| 全局标题 | 整个版图的主题 | 顶部或中心的标题 |

## 布局原则

- **空间隐喻**：相似的事物在空间上靠近
- **区域清晰**：不同子领域用颜色/边界明确区分
- **密度均匀**：避免某个区域过于密集而其他空旷
- **层次感**：重要参与者/流派用更大的标记
- **可浏览性**：读者应能快速扫视获得全局印象
