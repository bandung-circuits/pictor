# 论辩地图 / Debate Map

## 适用场景

展示**正反观点的对立结构**，包括支持论据、反驳论据、以及各方立场之间的回应关系。适合呈现学术争论、政策辩论、多方立场对比。

## 信息结构特征

当源文本包含以下特征时，适合使用论辩地图：

- 存在明确的正反两方或多方观点
- "支持者认为...反对者则认为..."
- 论点之间有直接的反驳或回应关系
- 某个主张同时有多条支持和反对证据
- 多个学者/团体对同一议题的不同立场

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| 中心议题 | 辩论的核心问题 | 顶部或中心的突出框 |
| 支持论点 | 赞同立场的论据 | 绿色/蓝色节点 |
| 反对论点 | 反对立场的论据 | 红色/橙色节点 |
| 回应连线 | 论点间的反驳/支持关系 | 带箭头连线，颜色区分 |
| 证据节点 | 支撑论点的具体证据 | 较小的附属节点 |

## 布局原则

- **对称布局**：正方和反方分列左右或上下
- **中心议题突出**：核心问题居于视觉焦点
- **颜色对比**：用鲜明的颜色对比区分正反方
- **层级深度**：从核心立场到具体证据逐层展开
- **回应关系清晰**：反驳连线用虚线或不同颜色标识
