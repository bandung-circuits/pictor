# 网络关系图 / Network Graph

## 适用场景

展示**实体之间的多对多关系网络**。适合将非线性的、相互交织的关系结构可视化，包括因果网络、利益相关方关系、知识图谱、引用网络、权力关系等。

## 信息结构特征

当源文本包含以下特征时，适合使用网络关系图：

- 多个实体之间的相互影响或依赖
- "A 影响 B"、"X 与 Y 相关"、"互相作用"
- 因果链或因果网络（非单一线性因果）
- 利益相关方之间的权力、资源或信息交换
- 概念之间的类比、对比、包含关系

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| 节点 | 表示一个实体/概念 | 圆形或圆角矩形，大小反映重要性 |
| 边/连线 | 表示关系 | 带箭头（有向）或无箭头（无向） |
| 边标签 | 描述关系类型 | 连线上的简短文字 |
| 节点颜色 | 区分实体类别 | 不同颜色代表不同类型 |
| 边粗细 | 关系强度 | 越粗表示关系越强 |
| 聚类分组 | 将相关节点归类 | 背景色区域或虚线框 |

## 布局原则

- **中心性**：最重要的节点居中，次要节点向外辐射
- **减少交叉**：尽量减少连线的交叉
- **颜色编码**：用颜色区分节点类别（如不同利益方、不同层级）
- **权重可视化**：节点大小 → 重要程度；连线粗细 → 关系强度
- **标签可读**：每个节点和关键连线都应有标签
- **复杂度控制**：单张图不超过 20-30 个节点
