# 象限图 / Quadrant Chart

## 适用场景

在 **2×2 矩阵**中定位事物，展示两个维度的交叉分类。适合策略定位、优先级矩阵、风险评估、分类决策。

## 信息结构特征

当源文本包含以下特征时，适合使用象限图：

- 两个维度的交叉分类（如"重要性 × 紧急性"）
- "高 X 低 Y"、"既 A 又 B"等二维定位描述
- 策略分析中的四类划分
- 需要为不同位置推荐不同策略
- BCG 矩阵、艾森豪威尔矩阵等经典模型

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| 两条轴 | 定义分析维度 | 十字交叉的坐标轴 |
| 四个象限 | 四种分类区域 | 用不同背景色标识 |
| 象限标签 | 每个象限的含义/策略 | 象限内的标题文字 |
| 定位标记 | 具体事物在矩阵中的位置 | 圆点或图标 |
| 轴端标签 | 维度的两极 | 轴两端的文字（如"高"/"低"） |

## 布局原则

- **正方形比例**：四个象限面积相等
- **颜色直觉**：用冷暖色调暗示优先级（如红=高优先，绿=低优先）
- **标记清晰**：每个定位点都有标签
- **象限命名**：每个象限有简短有力的策略名称
- **简洁为主**：不超过 15-20 个定位标记
