# 桑基流量图 / Sankey Flow Diagram

## 适用场景

用**宽度与流量成比例的带状连线**展示资源、价值、资本或信息从来源到目的地的流动与分配。适合将价值链、资源分配、资本流向等量化流动关系可视化。

## 信息结构特征

当源文本包含以下特征时，适合使用桑基流量图：

- 从一组来源流向一组目标的数据（如资金从投资者流向不同行业）
- 价值链分析（原料→加工→分销→消费）
- "其中 X% 流向了..."、"A 贡献了 Y 给 B"
- 资源的分配和再分配
- 多级分流或汇聚

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| 节点列 | 来源、中间站、目标 | 垂直排列的矩形 |
| 流量带 | 连接节点的比例宽度连线 | 弯曲的带状色块，宽度=流量 |
| 节点标签 | 标识每个来源/目标 | 节点旁边的文字 |
| 数值标注 | 标注具体流量数值 | 流量带上或旁边的数字 |
| 颜色编码 | 区分不同来源或类别 | 每个来源用不同颜色 |

## 布局原则

- **从左到右**：来源在左，目标在右，可有多个中间层
- **比例准确**：带的宽度严格与流量成正比
- **总量守恒**：左侧总宽度 = 右侧总宽度（除非有损耗）
- **颜色连贯**：同一来源的流量在整个路径中保持同色
- **避免交叉**：通过合理排序减少带的交叉
