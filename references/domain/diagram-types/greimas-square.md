# 格雷马斯方阵 / Greimas Square

## 适用场景

展示**语义对立关系的四元结构**，将一对二元对立拆解为四个位置（S1、S2、非S1、非S2），并展示它们之间的对立（contrary）、矛盾（contradictory）和蕴含（implication）关系。来源于结构主义语义学，广泛用于叙事分析和意识形态批评。

## 信息结构特征

当源文本包含以下特征时，适合使用格雷马斯方阵：

- 明确的二元对立（如自由 vs. 秩序、自然 vs. 文化）
- 存在"既不是 A 也不是 B"的中间或否定态
- 对意识形态结构的分析
- 叙事中人物或价值观的对立关系
- 概念的辩证关系（正题→反题→合题的变体）

## 核心视觉元素

| 元素 | 用途 | 常见表现 |
|------|------|----------|
| 四个位置 | S1、S2、非S1、非S2 | 正方形四角的节点 |
| 对立轴 | S1 ↔ S2 的对立关系 | 水平连线，标注"对立" |
| 矛盾轴 | S1 ↔ 非S1、S2 ↔ 非S2 | 对角虚线，标注"矛盾" |
| 蕴含轴 | S1 → 非S2、S2 → 非S1 | 垂直连线，标注"蕴含" |
| 综合位置 | 复合语义（如 S1+S2） | 中央或边线位置 |

## 布局原则

- **正方形布局**：四个位置严格排列在正方形的四角
- **关系线类型**：对立=实线、矛盾=对角虚线、蕴含=单向箭头
- **标注清晰**：每个位置和每条关系线都有明确的语义标签
- **颜色区分**：上方两个（正面概念）和下方两个（否定概念）用不同色调
- **保持简洁**：不添加额外装饰，保持结构主义的严谨感
