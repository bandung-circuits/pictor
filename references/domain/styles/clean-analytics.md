# clean-analytics

Clean, data-confident research visualisation style with teal as the dominant brand colour on white. Digitally precise, generous whitespace, oversized hero numbers, and circle/bubble signature shapes — designed for data-driven analysis and quantitative storytelling.

## Color Palette

- Primary: Teal (#4EBDBA) for accents, data labels, shape fills, and emphasis
- Teal scale: Deep teal (#3B9B9B) for emphasis and primary data series, mid teal (#6DCBC8) for secondary fills, light teal (#B5DEDE) for background fills and bubble shapes, very light teal (#E4F3F3) for subtle area fills
- Background: Clean white (#FFFFFF)
- Text: Black (#1A1A1A) for bold headlines, dark gray (#4A4A4A) for body content and annotations
- Accent 1: Coral/Salmon (#E87461) for categorical highlights and contrasting data series
- Accent 2: Warm orange (#F0A050) for secondary category labels
- Data colors: When multiple series are needed, use teal as primary, then coral (#E87461), purple (#7B68AE), amber (#D4A843), slate blue (#4A6FA5) — always with teal dominant

## Variants

| Variant | Focus | Visual Emphasis |
|---------|-------|-----------------|
| **Overview** | Concept maps, key messages, ecosystem diagrams | Teal circle/bubble compositions, geometric icons, bold mixed-weight headlines |
| **Data-study** | Charts, statistics, quantitative evidence | Oversized hero numbers, clean chart areas, clear axis labels |
| **Architecture** | System diagrams, relationship maps, workflows | Colour-coded category system (teal, coral, orange, purple), flow arrows, nested containers |

## Visual Elements

- Circles and bubbles as signature shapes — overlapping circles for Venn diagrams, sized circles for bubble charts, circular icon containers
- Rounded pill/capsule shapes for labels and category tags (teal, gray, or coral fills with white or dark text)
- Simple geometric line-art icons in circles for conceptual elements
- Clean horizontal and vertical dividers in teal
- Generous negative space — content is not crowded despite data density
- Focus purely on information content — no source citations, methodology notes, or institutional branding within the graphic

## Typography

- Extra bold condensed sans-serif for headlines — large and impactful
- Mixed-weight headlines for visual rhythm: key words in bold black, contextual words in regular weight with teal colour
- Oversized bold numerals as hero elements for statistics (number in black extra-bold, unit in regular weight)
- Clean sans-serif for body text, descriptions, and annotations
- Small sans-serif for secondary labels and footnotes

## Style Rules

**Do:**
- Use teal as the single dominant brand colour — it conveys analytical trust and modern professionalism
- Keep the background white and clean
- Present statistics as hero elements with oversized numerals when appropriate
- Use circles and rounded shapes as the geometric signature
- Use colour coding consistently across related elements (same category = same colour)
- Allow mixed-weight typography in headlines for visual rhythm

**Don't:**
- Use hand-drawn elements, textures, or rough edges — everything should be digitally precise
- Overcrowd the canvas — every element needs space to breathe
- Use decorative illustrations or cartoon elements — icons should be simple geometric line art
- Mix too many accent colours in a single composition — teal + one accent (coral or orange) is typical
- Add drop shadows, bevels, or 3D effects — surfaces are flat and clean
- Use gradients or glossy effects

Research data visualisations, quantitative analysis, system architecture diagrams, ecosystem maps, statistical dashboards, institutional capability overviews, data-driven briefing materials
