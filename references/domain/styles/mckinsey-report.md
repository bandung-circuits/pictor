# mckinsey-report

Authoritative institutional research style with a blue-dominant palette on white — inspired by the visual identity of McKinsey Global Institute publications. Dual-typeface system (serif headlines, sans-serif body), action titles as complete insight sentences, and generous whitespace that signals analytical rigor and institutional authority.

## Color Palette

- Primary: McKinsey Blue (#2563EB) for headings, data highlights, accent elements, and emphasis
- Dark navy (#1B2838) for primary chart data series, key figures, and strong visual anchors
- Secondary: Teal/Cyan (#14B8A6) for secondary data series and supporting highlights
- Tertiary: Light blue (#93C5FD) for third-level data, area fills, and gradient elements
- Background: Clean white (#FFFFFF) throughout — no dark backgrounds
- Text: Near-black (#1A1A1A) for body text and primary labels
- Supporting text: Gray (#6B7280) for footnotes, source citations, and secondary annotations
- Sidebar background: Very light gray (#F5F5F5) for boxed methodology or context sections
- Data colors: When multiple series are needed, use dark navy as primary, then blue (#2563EB), teal (#14B8A6), light blue (#93C5FD), and coral (#E87461) as a contrasting accent — always with blues dominant. Pink/magenta (#EC4899) reserved strictly for alert or "impossible" data categories.

## Visual Elements

- Action titles as complete sentences stating the analytical insight (e.g., "Rearranging US imports has become progressively more difficult.")
- Em-dash (—) bullet points for executive summary and key findings — not dots, not numbers
- Bold lead-in sentence pattern: first sentence of each bullet is bold, remainder is regular weight
- Direct data labeling — values placed next to or inside data elements, minimizing legends
- Minimal gridlines — light gray dashed lines only when necessary for reading values
- Pull quotes rendered as large blue serif text spanning full width — no quotation marks, just oversized blue serif text serving as a visual breathing point
- Focus purely on information content — no source citations, exhibit numbering, methodology notes, or institutional branding within the graphic
- Clean horizontal rules as subtle section dividers
- Simple monochromatic line-art icons when conceptual elements need visual representation

## Typography

- Bold serif (Georgia or similar) for all titles and headings — this maps to McKinsey's custom Bower typeface, conveying institutional gravitas
- Clean sans-serif (Arial, Helvetica) for body text, chart labels, annotations, and all secondary text
- Dual-typeface contrast is the defining typographic feature: serif for hierarchy/emphasis, sans-serif for everything else
- Mixed-weight serif headlines: key insight words in bold, contextual phrases in regular weight
- Oversized serif numerals as hero elements when featuring key statistics
- Small sans-serif for "Exhibit N" labels, footnotes, source citations

## Style Rules

**Do:**
- Use blue as the single dominant color family — blues convey institutional trust, analytical depth, and constancy
- Maintain dual-typeface discipline: serif for titles and pull quotes, sans-serif for body and labels
- Write chart titles as complete analytical sentences (action titles) — not just topic labels
- Use em-dash (—) bullets for summary sections with bold lead-in sentences
- Keep backgrounds white and clean — generous margins and negative space signal serious research
- Use direct data labels to minimize the need for separate legends
- Allow pull quotes as large blue serif text for visual rhythm in dense layouts

**Don't:**
- Use dark backgrounds — McKinsey reports are always white-background in formal publications
- Use decorative illustrations, cartoon elements, or playful graphics — this is institutional research
- Use more than 4-5 colors in a single composition — the blue family + one accent is typical
- Add drop shadows, bevels, 3D effects, or glossy surfaces — everything is flat and precise
- Use rounded corners on data containers or chart areas — rectangular precision throughout
- Mix serif and sans-serif roles — never use serif for body text or sans-serif for main titles
- Use gradient fills on data elements — fills should be solid and flat
- Add decorative borders or ornamental frames — minimalism is the operating principle
- Use bullet dots or numbered lists where em-dash bullets are appropriate
