# network-graph

Multiple nodes connected by many-to-many relationships — no single dominant center. Nodes are positioned to reveal clusters, influence paths, and connection density.

## Structure

- Multiple nodes of varying size/importance (no single center)
- Directed or undirected edges connecting any node to any other
- Node size or color encoding importance, category, or frequency
- Edge thickness or style encoding relationship strength or type
- Natural clustering of densely connected nodes

## Best For

- Causal networks and influence diagrams
- Knowledge graphs and concept relationships
- Social network and stakeholder interaction maps
- Trade or cooperation networks between countries/organizations
- Citation networks and intellectual lineage

## Visual Elements

- Circles or rounded shapes for nodes, sized by importance
- Curved or straight lines for edges, with optional arrowheads
- Color grouping for node categories or clusters
- Edge labels for relationship types (causes, enables, blocks)
- Subtle background regions to highlight clusters

## Text Placement

- Title at top
- Node labels inside or beside each node
- Edge labels along connections (sparingly)
- Legend for color/size encoding if not self-evident
- Optional annotation highlighting key paths or clusters

## Recommended Pairings

- `technical-schematic`: Analytical causal diagrams
- `clean-analytics`: Data-driven relationship analysis
- `mckinsey-report`: Strategic influence mapping
- `corporate-memphis`: Business ecosystem networks
