# parallel-tracks

Multiple horizontal lanes running in parallel across a shared timeline or progression axis — each lane tracks one entity's evolution, enabling side-by-side comparison of concurrent developments.

## Structure

- Shared horizontal axis (time, phase, or progression)
- 2–5 horizontal swim lanes, each representing one entity/thread
- Events or milestones placed at positions along each lane
- Lane labels on the left identifying each entity
- Optional cross-lane connectors showing interactions or influences between tracks

## Variants

| Variant | Focus | Visual Emphasis |
|---------|-------|-----------------|
| **Timeline** | Concurrent histories, parallel chronologies | Date markers on shared axis, event nodes per lane |
| **Evolution** | How multiple entities transform through the same phases | Phase columns, state descriptions per lane |

## Best For

- Multi-country or multi-region policy comparisons over time
- Technology evolution across competing platforms
- Parallel project timelines
- Biographical comparisons (multiple lives across same era)
- Legislative or institutional development across jurisdictions

## Visual Elements

- Distinct color per lane for quick identification
- Horizontal lane dividers (subtle lines or alternating background bands)
- Event markers (dots, icons, or cards) positioned along each lane
- Shared time/phase labels above or below the axis
- Cross-lane arrows or dashed lines for interaction events (sparingly)

## Text Placement

- Title at top
- Lane labels at left edge of each lane
- Time/phase markers along horizontal axis
- Event descriptions beside or below each marker
- Optional summary annotation at bottom
